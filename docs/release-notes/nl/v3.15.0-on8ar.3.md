**Firmware-regel in de MQTT-mail.** De mail met je persoonlijke observer-login zette `mqtt://` voor de server in de commando's voor de Dutch-MeshCore observer-firmware. Firmware van voor 19 oktober aanvaardt dat niet. De mail zet nu alleen de hostnaam (`set mqtt1.server emqx.on8ar.eu`). Kreeg je de mail al, vraag hem dan opnieuw aan op je accountpagina: je krijgt dezelfde login, nu met de juiste regel.

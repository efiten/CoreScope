Het bereik-paneel van een node laadt sneller.

**Bereik.** Het paneel "Bereik" op de pagina van een node zocht bij elke opvraging door alle pakketten van de gekozen periode naar die node. Dat duurde op deze server zo'n 2 seconden per node. Er is nu een index die per hop bijhoudt in welke pakketten een node voorkomt, voor de laatste 14 dagen. Het paneel leest die index rechtstreeks. Voor een langere periode dan 14 dagen blijft het de oude, tragere zoekmethode gebruiken.

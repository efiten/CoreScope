Twee snelheidsfixes, geen nieuwe functies.

**Minder hangende pagina's.** Sommige pagina's lieten tegelijk de rest van de analyser wachten, tot een halve minuut of langer, ook voor wie iets heel anders opvroeg. Dat zat in hoe de server zijn gegevens afschermde terwijl hij de database raadpleegde. Op onze testomgeving vielen de uitschieters boven 5 seconden onder belasting volledig weg.

**Reach sneller.** De Reach-pagina van een node had per opvraging 3 seconden of meer nodig, en liep bij drukte uit tot een time-out. Die zoekopdracht duurt nu ongeveer 2 seconden.

De Reach-pagina blijft de zwaarste van de analyser: de eerste keer dat je een node opent, duurt het nog even. Daarna komt hij 5 minuten uit het geheugen.

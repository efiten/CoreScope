De analyser draait nu op CoreScope v3.13.0, de nieuwe officiële release. Bijna alles daaruit staat hier sinds gisteren al live, dus deze update is klein.

**Nieuw: adverts per node gegroepeerd.** In het detail van een node staan de recente adverts nu in groepen: *Flood adverts*, *Direct adverts (empty path)*, *Mixed* als hetzelfde advert langs beide wegen binnenkwam, en *Other / unknown* als er nog geen gegevens over de route zijn. Een leeg pad betekent alleen dat er bij ontvangst geen hops meer in stonden, niet dat de node rechtstreeks of dichtbij zond.

Repeater Naming Convention

Standardized formats for MeshCore repeater names, as used on the Belgian nodenet.be and radio-actief.be networks.

Format

CC-LOC-NAME-TYPE-NUM
FieldLengthDescriptionExample
CC2ISO country codeBE, NL, DE
LOC3UN/LOCODE city codeBRE, ANT, BLZ
NAME≤9Free name (letters, digits, spaces, underscores)Tabaart, MT Zolder
TYPE3Repeater type code (see table below)EBP, DIS
NUM2Sequence number01, 02

Maximum total length: 23 characters.

Repeater Type Codes

CodeFull nameDescription
CORCore RepeaterLong backbone links connecting smaller distribution areas. High altitude, autonomous with battery backup.
DISDistributionMedium to long range, reliable connection to at least one core node. Urban high points, autonomous with battery backup.
EDGEdgeRooftop and residential nodes. Any height. Mains power allowed.
EBPEdge · Battery PoweredEdge variant — battery powered.
ESPEdge · Solar PoweredEdge variant — solar powered.
EMPEdge · Mains PoweredEdge variant — mains powered.
MOBMobileVehicle-mounted, carried, or temporarily deployed. Free category.

LOCODE City Code Lookup

The 3-letter city code is taken from the UN/LOCODE standard. Look up codes for your country:

  • Netherlands (NL)
  • Germany (DE)
  • United Kingdom (GB)
  • France (FR)
  • All other countries

Alternative: radio-actief.be convention

Some operators use the radio-actief.be convention instead — both are used interchangeably and CoreScope decodes either. It shares the CC-LOC prefix but replaces the name/type fields with an operator ID and an optional power-source emoji.

CC-REGION-OPERATOR-ID⚡ emoji
FieldDescriptionExample
CCISO 3166-1 country codeBE, DE
REGION3-letter UN/LOCODE city code, or a 2–3 letter ISO 3166-2 region (e.g. a German Bundesland)GNE, NW
OPERATOR-IDOperator identity (see table below)RRY01, ON7MHZ
emojiOptional power source (see table below)☀️ ⚡️ 🔋

Maximum total length: 32 characters. The separator after the region code may be a dash - or a space.
